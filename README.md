# 🌤 WeatherSphere - Interactive Weather Dashboard

## 📖 Overview

WeatherSphere is a modern and interactive weather forecasting web application that provides real-time weather data and temperature trends for any city using the OpenWeatherMap API.

The application fetches weather forecast data and visualizes temperature variations through dynamic charts powered by Chart.js, offering users an engaging and user-friendly experience.

---

## 🚀 Features

### 🌍 Weather Forecasting

* Search weather by city name
* Real-time weather forecast data
* Temperature trend visualization

### 📊 Data Visualization

* Interactive temperature chart
* Smooth chart rendering using Chart.js
* Responsive graph updates

### 🎨 Modern UI
